# CodePortfolio

Plataforma full-stack para publicar portafolios de código, interactuar con otros
desarrolladores y gestionar vacantes y postulaciones.

## Componentes

- `codeportfolio-backend`: API ASP.NET Core 8.
- `codeportfolio-frontend`: SPA React 19 + Vite.
- `database/init.sql`: esquema PostgreSQL 16 compatible con la API.
- `docker-compose.yml`: PostgreSQL, backend y frontend.

Consulta [la documentación del backend](codeportfolio-backend/README.md) para la
configuración y puesta en marcha.
