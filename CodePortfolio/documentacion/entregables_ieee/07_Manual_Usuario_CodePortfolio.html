1.Introducción

CodePortfolio permite publicar proyectos de software, descubrir perfiles, interactuar con la comunidad y consultar vacantes. Es una aplicación web; no requiere instalación.

2.Requisitos y acceso

  • Usa Chrome, Firefox, Edge o Safari actualizado y una conexión a Internet.
  • En Docker local abre http://localhost:3000.
  • Para registrarte, selecciona Crear cuenta, completa los datos y usa un correo único.
  • Inicia sesión con el correo y contraseña. Cierra sesión cuando uses un equipo compartido.

4.Crear un proyecto

  1. Abre Mis proyectos y selecciona crear.
  2. Escribe título, descripción y enlaces de repositorio o demostración cuando apliquen.
  3. Guarda como borrador mientras lo preparas.
  4. Cámbialo a publicado para mostrarlo en el perfil y el feed.
  5. Desde un proyecto propio puedes editarlo, sustituir su imagen o eliminarlo.
ImágenesCarga JPG, PNG, WEBP o GIF reales de hasta 5 MB. Los borradores no son visibles para otros usuarios.

5.Comunidad, perfiles y empleos

  • Abre perfiles para consultar información pública y proyectos publicados.
  • Sigue desarrolladores para verlos en el feed de seguidos.
  • Da o retira una reacción y publica comentarios respetuosos.
  • En Empleos, abre una vacante, selecciona Postular y envía una carta opcional.
  • Revisa Mis postulaciones para conocer su estado. Solo se admite una postulación por usuario y vacante.
