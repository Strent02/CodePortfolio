1.Propósito

Este manual permite instalar, comprender y evolucionar CodePortfolio según el alcance implementado: SPA React, API REST, PostgreSQL, imágenes persistentes y Docker Compose.

2.Arquitectura

4.Configuración y ejecución

Copia .env.example a .env y define las credenciales PostgreSQL, JWT_KEY de al menos 32 bytes y, opcionalmente, el administrador inicial. Desde la raíz ejecuta:

docker compose up --build
# frontend: http://localhost:3000
# API local: http://localhost:5102
SecretosNo versionar .env, contraseñas, JWT ni respaldos.

5.Seguridad

  • BCrypt para contraseñas y hash SHA-256 para refresh tokens.
  • JWT con firma, emisor, audiencia y expiración.
  • Autorización por rol y propiedad de recursos.
  • Rate limit de autenticación: 10 solicitudes/minuto por cliente.
  • Validación binaria de imágenes y límite de 5 MB.
  • CORS explícito, HSTS fuera de desarrollo y respuestas de error neutras.

6.Cambios y pruebas

Las migraciones de Entity Framework en Migrations/ versionan el esquema. Todo cambio de modelo debe revisar su migración y probarse sobre una copia. Antes de integrar cambios, ejecutar lint y build del frontend y las pruebas .NET disponibles:

cd codeportfolio-frontend && npm ci && npm run lint && npm run build
dotnet test codeportfolio-backend.Tests/CodePortfolio.Tests.csproj
